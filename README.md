# SalesPitch Accelerator

A high-impact, lightning-fast one-shot project template designed for live client sales pitches. 
Allows real-time customization of metrics, client names, and solution titles during a presentation to demonstrate extreme execution velocity.

## Features
- **Live Pitch Customization**: Instantly tailor client names and solution focus in real-time.
- **Enterprise Metrics Grid**: High-contrast, elite dark-themed UI (Hermes Red accent).
- **Instant Deployment**: Ready for immediate deployment to Vercel or any virtual server environment.

## Local Development
```bash
npm install
npm start
```
